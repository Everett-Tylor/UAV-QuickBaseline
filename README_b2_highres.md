# B2 第三轮：高分辨率比较与微调

当前已验证的类别校正版 mIoU 为 75.5002%，旧 B2 为 74.9372%。
640 分辨率的第二轮微调仍可能产生更高结果，因此本轮等待第二轮完全结束后才使用 GPU。
不会与现有训练并行争用显存，也不会从尚未写完的权重文件初始化。

## 固定实验方案

1. 从第二轮 `selection.json` 读取最终胜出的单模型、类别校正和验证分数。
2. 先对相同权重比较 640/768/896 三尺度及水平翻转，保留所有验证结果。
3. 在同一权重上做真实 768 分辨率反向传播/EMA 测试；通过后训练 3 轮。
   batch 1、累积 8、编码器 LR 2e-6、解码器 LR 2e-5，保留较温和的类别加权
   和第二轮的几何、颜色、gamma 增强。验证集不参与训练。
4. 对新权重分别测试 512/640/768 与 640/768/896；保持相同的类别校正候选网格、
   调参/复核划分、类别 ID 和原始分辨率统计方式。
5. 先按调参子集确定唯一候选，再检查该候选是否在调参、复核、整体三个指标上
   都超过第二轮最终结果；否则保留第二轮预测包，不声称提升。

这些比较重复使用历史验证集，复核部分不是全新独立测试集。官方提分仍需平台反馈。
只推理一个 B2 模型，不做模型集成，不使用 test2 训练或调参。

```powershell
python work/segformer-b2/b2_highres_pipeline.py --workspace .
```

源码位于其他目录时修改脚本路径。脚本使用第二轮的已保存数据路径和固定输出目录。
状态与日志：`outputs/segformer_b2_highres/`。
只有确认更好的模型才会生成 `submission_b2_highres.zip`；否则 `status.json`
会记录 `complete_no_improvement` 及保留的旧预测包。此前实验失败或八小时仍未结束会明确停止报错。

验证：六项类别校正/方案选择测试通过，Python 语法检查通过。
768 分辨率 GPU 测试会在上一轮结束后执行，当前不声称它或正式微调已经完成。
